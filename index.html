S/4HANA on AWS, Microsoft Azure or Google Cloud

A decision-support prototype. It shows where detailed evaluation effort is worth spending. It is not a pricing calculator, not a substitute for vendor sizing and not a full TCO model.

What this tool compares

Route A - SAP-managed bundle (SAP Cloud ERP Private, earlier RISE with SAP): EXCLUDED. SAP runs the whole system for one negotiated price. There is no public price list, so no number for this route could be traced to a source.

Route B - customer-managed: THIS IS WHAT THE TOOL COMPARES. The company rents servers, storage and network from AWS, Microsoft Azure or Google Cloud and runs S/4HANA there with its own SAP licence. These prices are public and dated, so every number can be checked.
